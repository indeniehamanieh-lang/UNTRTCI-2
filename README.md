# UNTRTCI Mobile

Application de l'Union Nationale des Techniciens de la Radio et de la Télévision de Côte d'Ivoire.
Site React (Vite + TanStack Router) + base Supabase, emballé en application Android (Capacitor).

- Développement : `npm install` puis `npm run dev`
- Base de données : exécuter `supabase/setup.sql` dans l'éditeur SQL de Supabase
- APK : voir `LISEZMOI-APK.md`
